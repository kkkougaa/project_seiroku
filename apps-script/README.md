# 행사 관리 사이트 연결하기

관리 사이트(`www/admin/`)는 화면만 있고, 데이터는 **구글 시트**에 있어요.
시트에 붙인 **Apps Script**가 둘 사이를 이어줘요. 서버는 따로 필요 없어요.

```
관리 사이트 (GitHub Pages)  ──비밀키──▶  Apps Script 웹 앱  ──▶  구글 시트 (비공개)
```

## 처음 한 번만

1. 구글 드라이브에서 **새 스프레드시트**를 만들어요. (이름은 아무거나)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 원래 있던 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs`를 통째로 붙여넣고 저장(⌘S)해요.
4. 시트 탭으로 돌아가서 **새로고침**하면 위 메뉴에 **관리 사이트**가 생겨요.
5. **관리 사이트 → 1. 처음 설정**을 눌러요.
   - 처음엔 권한 허용 창이 떠요. 내 계정을 고르고 **고급 → (안전하지 않음)으로 이동 → 허용**을 눌러요. 내가 만든 스크립트라서 나오는 경고예요.
   - 탭이 만들어지고, 작년 시트의 **섭외 진행 + 확정 작가 리스트**가 `작가` 탭 하나로 합쳐져서 들어와요.
   - 마지막에 **비밀키**가 나와요. 복사해 두세요. (나중에 메뉴 → 비밀키 보기로 다시 볼 수 있어요)
6. Apps Script 화면 오른쪽 위 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 배포 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
7. 관리 사이트(`https://<아이디>.github.io/project_seiroku/admin/`)를 열고 웹 앱 URL과 비밀키를 넣어요.

> "모든 사용자"여도 **비밀키가 없으면 아무것도 못 읽어요.** 시트 자체는 공유하지 않아도 돼요(비공개 그대로).
> 키가 새어나간 것 같으면 메뉴 → **비밀키 새로 만들기**를 누르면 예전 키는 바로 막혀요.

## 구글 로그인 켜기 (추천)

허용한 구글 계정만 들어오게 해요. 동료는 사이트를 열고 **구글로 로그인**만 누르면 돼요.

1. https://console.cloud.google.com 에서 **새 프로젝트**를 만들어요. (이름: 행사 관리)
2. **Google 인증 플랫폼(OAuth 동의 화면) → 시작하기**
   - 앱 이름: 행사 관리, 지원 이메일: 내 메일, 대상: **외부**, 연락처: 내 메일 → 만들기
3. **클라이언트 → 클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://kkkougaa.github.io`
   - 만들기 → 나오는 **클라이언트 ID**(`….apps.googleusercontent.com`)를 복사해요.
4. **대상 → 앱 게시**를 눌러 프로덕션으로 바꿔요. (이메일·프로필만 쓰니까 구글 검수는 필요 없어요)
5. 클라이언트 ID를 두 곳에 넣어요.
   - `www/admin/settings.js` 의 `googleClientId`
   - `apps-script/Code.gs` 의 `GOOGLE_CLIENT_ID`, 들어올 계정은 `ALLOWED_EMAILS`
   - Code.gs를 고쳤으면 아래 "Code.gs를 고쳤을 때"대로 다시 배포해요.

- 시트 주인 계정은 항상 들어올 수 있어요.
- 계정 추가/빼기는 시트 메뉴 **관리 사이트 → 구글 계정 허용 관리**로도 할 수 있어요. (코드 수정 없이 바로 반영)
- 로그인은 1시간마다 다시 확인해요. 전에 로그인한 브라우저는 대부분 자동으로 다시 로그인돼요.

## 동료에게 주기 (비밀키 링크 방식)

1. 시트 메뉴 **관리 사이트 → 동료 추가**를 누르고 이름을 넣어요.
   (처음 한 번은 웹 앱 주소를 물어봐요. 배포 → 배포 관리에 있는 `/exec` 주소를 넣어요)
2. 그 사람 전용 링크가 나와요. **링크 복사** → 그 사람에게만 따로 보내요.
3. 동료가 링크를 열면 그 기기에 자동으로 연결돼요. 주소나 키를 입력할 필요가 없어요.

- 사람마다 키가 달라서, **동료 목록 / 연결 끊기**로 한 명만 막을 수 있어요. (나머지는 그대로)
- 주문 처리 탭의 `수정한 사람` 열에 누가 고쳤는지 남아요.
- 링크 = 열쇠예요. 단톡방이나 공개된 곳에는 올리지 마세요. 새어나가면 그 사람 링크만 끊고 새로 만들어 주면 돼요.
- 링크의 `#` 뒷부분은 GitHub 서버로 전송되지 않고, 사이트가 열리자마자 주소창에서 지워요.
- 내 다른 기기(아이패드, 폰)에서 쓸 때는 사이트 **설정 → 내 연결 링크 복사**를 쓰면 돼요.

## Code.gs를 고쳤을 때

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 눌러야 반영돼요. 주소는 그대로예요.
(새 배포를 만들면 주소가 바뀌어서 사이트 설정도 바꿔야 해요)

clasp로 올리는 방법 (이 폴더에 `.clasp.json`이 있어요):

```bash
npx @google/clasp@3.4.1 login
```

```bash
npx @google/clasp@3.4.1 push -f
```

```bash
npx @google/clasp@3.4.1 redeploy AKfycbxtSj0sZ3KUpgC11YHqN_HDLPYhbzyRV61sk00vSbxHpw9o95DiF7ULEMYbqw3ddghL -d "관리 사이트 API"
```

## 탭 구조

| 탭 | 내용 | 누가 채우나 |
|---|---|---|
| 작가 | 섭외 + 확정 작가 정보. `수락 여부`가 "수락"이면 확정 작가. `No` = 족자봉 넘버 | 사이트 / 시트 |
| 선입금 리스트 | 위치폼 엑셀 원본 그대로 (A~AC열) | 사이트에서 붙여넣기 |
| 입금기록 | 통장 거래내역 원본 그대로 | 사이트에서 붙여넣기 |
| 주문 처리 | 주문번호별로 사이트에서 고친 것 (족자봉 확정, 입금 연결, 메모) | 사이트 |
| 추가 수량 | 주문 밖에서 더 만드는 족자봉·엽서북 | 사이트 / 시트 |
| 수입, 비용 | 정산용 | 사이트 / 시트 |
| 예외기록 | 메모 | 사이트 / 시트 |
| 설정 | 가격, 작가 여분, 분배 비율, 현재 잔고 | 사이트 / 시트 |

- 원본 탭(선입금 리스트, 입금기록)은 다시 붙여넣어도 **주문 처리**가 주문번호로 남아 있어서 작업한 게 안 날아가요.
- 원본 탭은 전부 글자로 저장해서 환불계좌가 `3.33E+12`처럼 깨지지 않아요.
- 시트에서 직접 고쳐도 돼요. 사이트에서 **새로고침**을 누르면 바로 보여요. 열 **이름**만 바꾸지 마세요.

## 연습해보기

사이트 **설정 → 테스트 데이터**에서 작년 선입금 주문, 작년 통장 입금내역을 따로 불러올 수 있어요.
다 써봤으면 같은 곳의 **선입금 내역 초기화**(선입금 리스트 + 주문 처리), **입금내역 초기화**로 날려요.

## 작가 프로필 사진

작가 탭의 X 아이디로 프로필 사진 주소를 받아서 `프로필 사진` 열에 저장해요. 한 번 받으면 다시 안 받아요.
작가가 사진을 바꿔서 이미지가 깨지면 그 사람 것만 알아서 다시 받아요. (fxtwitter → unavatar 순서로 찾아요)

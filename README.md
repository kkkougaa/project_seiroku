# 부스 포스

동인 행사 부스에서 쓰는 오프라인 포스예요. 현장 판매, 선입금 수령, 재고 관리, 정산을 한 화면에서 처리해요.

- 인터넷이 없어도 돌아가요. 데이터는 **각 기기 안에만** 저장돼요.
- 부스 A, 부스 B는 데이터가 따로예요. 처음 켤 때 이 기기가 어느 부스인지 골라요.
- 아이패드, 맥북은 **웹앱**으로, 갤럭시 탭은 **APK**로 설치해요.

## 폴더 구조

```
www/admin/           ← 행사 관리 사이트 (작가, 선입금, 입금 대조, 제작 수량, 정산)
apps-script/         ← 관리 사이트와 구글 시트를 잇는 Apps Script (README 참고)
www/                 ← 앱 본체 (이것만 있으면 돌아가요)
  config.js          ← 부스 이름, 상품, 가격, 재고, 계좌번호 (여기만 고치면 돼요)
  app.js, style.css  ← 화면과 동작
  sw.js              ← 오프라인 캐시
android/             ← 갤럭시 탭용 APK 프로젝트 (Capacitor)
.github/workflows/   ← GitHub에 올리면 APK 빌드와 웹 배포를 자동으로 해줘요
```

## 1. 상품 바꾸기

**앱 안에서 바꾸기 (추천):** 설정 → 부스 / 상품에서 부스 이름, 상품 추가·편집·삭제·순서, 사진, 가격, 재고, R18, 선입금 전용, 종류(알파벳), 공용 재고를 바꿀 수 있어요.
바꾼 내용과 사진은 **그 기기에만** 저장되고, 백업 파일에 함께 들어가요. 다른 기기에도 똑같이 쓰려면 백업 파일로 되살리면 돼요.

**파일로 기본값 바꾸기:**

`www/config.js`를 열어서 부스별 `products`를 고쳐요.

```js
{ id: 'a1', name: '아크릴 스탠드 하루', price: 15000, stock: 30 },
```

- `id`는 행사 시작 후에는 바꾸지 마세요. 판매 기록이 id로 저장돼요.
- 가격과 처음 재고는 앱의 **설정 → 가격과 처음 재고**에서도 바꿀 수 있어요. (그 기기에만 적용)
- `stock`은 행사 시작 때 가져간 수량이에요. 현장에서 늘거나 줄면 앱의 **재고·정산 → 조정**으로 처리해요.
- 파일을 고친 뒤에는 `www/sw.js`의 `VERSION` 숫자를 올려 주세요. (예: `booth-pos-v2`) 그래야 설치된 웹앱이 새 파일을 받아요.

## 2. 선입금 명단 양식 (CSV)

구글폼 응답 시트나 엑셀에서 **CSV로 저장**한 파일을 불러와요. 앱의 **설정 → 양식 예시 파일 받기**로 예시를 받을 수 있어요.

| 주문번호 | 타임스탬프 | 이름 | 전화번호 | 입금확인 | 아크릴 스탠드 하루 | 회지 여름의 끝 | … |
|---|---|---|---|---|---|---|---|
| P001 | 2026-10-10 21:00 | 김하늘 | 010-1234-1234 | O | 1 | 2 | … |

- **꼭 필요한 열:** 이름, 전화번호, 그리고 상품 열
- 상품 열 이름은 `config.js`의 상품 이름과 같게 맞춰요. (띄어쓰기, 괄호, 「」 는 무시해요)
- 구글폼 표 질문처럼 `수량 [아크릴 스탠드 하루]` 형태도 알아봐요.
- 두 부스 상품이 한 파일에 같이 있어도 돼요. 각 기기는 **자기 부스 상품이 있는 사람만** 가져가요.
- `입금확인` 열이 있으면 O, 확인, 완료 같은 값이 있는 줄만 가져와요. 열이 없으면 모두 가져와요.
- 주문번호, 이름/닉네임/성함, 전화번호/연락처 같은 열 이름은 알아서 찾아요.
- 엑셀에서 저장한 한글 CSV(EUC-KR)도 읽어요.
- 명단을 다시 불러와도 이미 받아간 기록은 그대로 남아요. (주문번호 열이 있으면 더 정확해요)

### 테스트용 선입금

설정 → **테스트용 선입금 넣기**를 누르면 가짜 손님 40명이 들어가요. (뒷자리 1234가 3명, 입금 미확인 3명 포함)
진짜 명단을 넣기 전에는 설정 → **판매·선입금 기록만 지우기**로 테스트 기록을 지워 주세요. (상품 설정은 그대로 남아요)

## 3. 아이패드, 맥북에 웹앱으로 설치하기

웹앱은 한 번은 인터넷으로 받아야 해요. GitHub Pages로 올리는 게 제일 쉬워요.

1. GitHub에 새 저장소를 만들고 이 폴더를 통째로 올려요.
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔요.
3. `main` 브랜치에 올리면 `웹앱 올리기` 작업이 돌고, `https://<아이디>.github.io/<저장소>/` 주소가 생겨요.
4. **행사 며칠 전, 인터넷 되는 곳에서**
   - 아이패드: 사파리로 주소 열기 → 공유 버튼 → **홈 화면에 추가**
   - 맥북: 크롬으로 주소 열기 → 주소창 오른쪽 **설치** 버튼
5. 홈 화면 아이콘으로 한 번 열어서 부스를 고르고, **비행기 모드로 다시 열어서** 잘 열리는지 확인해요.

> 아이패드는 꼭 **홈 화면 아이콘**으로 열어 주세요. 사파리 탭으로 쓰면 한동안 안 연 사이트의 데이터를 사파리가 지울 수 있어요.

## 4. 갤럭시 탭에 APK 설치하기

### 방법 A. GitHub에서 자동으로 만들기 (추천)

1. 위 3번처럼 GitHub에 올리면 `안드로이드 APK 만들기` 작업이 자동으로 돌아요. (5분 정도)
2. 저장소 **Actions** 탭 → 완료된 작업 → 아래 **Artifacts**의 `booth-pos-apk`를 받아요.
3. 압축을 풀면 `app-debug.apk`가 나와요. 갤럭시 탭으로 옮겨서 열고 설치해요.
   (처음엔 "출처를 알 수 없는 앱 설치"를 허용해 달라고 나와요)

### 방법 B. 맥북에서 직접 만들기

Android Studio를 설치한 뒤:

```bash
npm install
```

```bash
npm run android:build
```

`android/app/build/outputs/apk/debug/app-debug.apk`가 생겨요.

### 참고: APK 없이 쓰기

갤럭시 탭 크롬에서 웹앱 주소를 열고 **메뉴 → 홈 화면에 추가 → 설치**를 눌러도 앱처럼 설치돼요. APK 빌드가 막히면 이 방법을 써요.

## 족자봉 모니터 (외장 모니터)

부스 A 아이패드 프로에 USB-C 외장 모니터를 연결해서, 지금 조회한 손님의 족자봉 알파벳을 크게 띄워요. 인터넷이나 무선은 필요 없어요.

- 필요한 것: M1 칩 이후 아이패드 프로 (외장 모니터를 '확장 화면'으로 쓰려면 스테이지 매니저가 필요해요)
- **포스와 모니터를 둘 다 사파리에서 열어야 해요.** 홈 화면 앱과 사파리는 저장 공간이 달라서 서로 연결되지 않아요.

1. 사파리로 포스 주소를 열고 부스 A를 골라요.
2. 설정 → **족자봉 모니터 열기**를 누르면 새 창이 열려요.
3. 스테이지 매니저를 켜고, 모니터 창을 외장 모니터 쪽으로 옮겨요.
4. 포스에서 번호를 조회하면 모니터에 알파벳이 바로 떠요. 전달 완료를 누르면 회색으로 바뀌고, 다음 손님을 조회할 때까지 그대로 남아 있어요.

## 5. 행사 당일 체크리스트

- [ ] 각 기기에서 부스가 맞게 골라져 있는지
- [ ] 선입금 명단 CSV를 불러왔는지 (설정 탭)
- [ ] 계좌번호가 맞는지 (현장 구매 → 계좌이체 화면)
- [ ] 비행기 모드에서 판매 → 수령 → 백업까지 한 번 해봤는지
- [ ] 쉬는 시간마다 **설정 → 백업 파일 내보내기** (1시간 넘으면 위에 주황색으로 알려줘요)
- [ ] 끝나고 **정산 CSV 내보내기**

## 데이터 안전

- 모든 기록은 기기의 브라우저 저장소(APK는 앱 저장소)에 바로 저장돼요.
- 앱을 지우거나 브라우저 데이터를 지우면 기록도 사라져요. 그래서 백업 파일이 중요해요.
- 백업 파일은 다른 기기에서 **설정 → 백업 파일로 되살리기**로 그대로 옮길 수 있어요. 기기가 고장 나도 다른 기기로 이어서 할 수 있어요.

## 행사 관리 사이트

`https://<아이디>.github.io/<저장소>/admin/` 에서 열려요. 구글 시트를 데이터베이스로 써요.
연결 방법은 [`apps-script/README.md`](apps-script/README.md)를 봐 주세요. 연결 전에는 **둘러보기**로 가짜 데이터를 써볼 수 있어요.

- **작가**: 섭외 수락 여부만 바꾸면 확정 작가 목록이 자동으로 만들어져요. 원고 제출, 현장 수령, 후기 관리
- **주문**: 위치폼 엑셀을 붙여넣으면 족자봉 넘버("2,27,18", "9번 / 11번", "2호×2")를 자동으로 나눠요
- **입금 대조**: 통장 내역의 입금자명 + 금액으로 주문을 자동 연결. 나눠서 입금한 것도 손으로 여러 건 연결 가능
- **제작 수량**: 넘버별 주문 + 작가 여분 + 추가 수량
- **정산**: 비용, 수입, 개인 선정산, 분배 비율로 사람별 금액 계산 + 검증
- **포스로 내보내기**: 같은 브라우저의 포스로 바로 보내거나(설정 → 관리 사이트에서 받기) CSV로 받아요 (족자봉 1→A 변환)
- **테스트 데이터**: 설정에서 작년 주문, 입금내역 샘플을 따로 불러오고 초기화할 수 있어요
- **구글 로그인**: 허용한 구글 계정만 들어와요 (설정 방법은 apps-script/README.md)

데이터는 저장소에 들어가지 않아요. 웹 앱 주소와 비밀키는 쓰는 브라우저에만 저장돼요.
